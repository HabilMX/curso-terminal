# La sala de guardia de la lección 03, «Ver lo que hay dentro».
#
# Esta lista es la única definición de la sala. La leen tres comandos:
#   prepara 03    arma en ~/practica/03/ lo que dicen los renglones de archivos
#   simula 03     agrega a arranque.log los renglones «crece», uno cada pocos segundos
#   verifica 03   revisa que la sala siga intacta y compara tus respuestas con lo que
#                 dicen los archivos
# Así no hay dos copias que se puedan contradecir.
#
# Las columnas van separadas por UN tabulador, no por espacios, igual que en la 02.
# prepara revisa TODA la lista antes de borrar o crear nada: cada ruta tiene que quedar
# adentro de ~/practica/03/ solo por cómo está escrita (no vacía, no absoluta, sin «.»
# ni «..» ni tramos vacíos). Si una no, no prepara nada.
#
# Lo que prepara arma. Las rutas van dentro de ~/practica/03/:
#   carpeta      ruta   fecha
#   texto        ruta   fecha        un archivo de texto: sus renglones son los «linea»
#                                    con la misma ruta, en el orden en que aparecen aquí
#   linea        ruta   texto        un renglón de ese archivo (sin tabuladores adentro)
#   numerado     ruta   fecha   N    N renglones: «renglón 001 de N», «renglón 002 de N»…
#   bitacora     ruta   fecha   inicio   paso   renglones   semilla   rechaza   huella
#   bitacora-gz  (las mismas columnas)   la bitácora, comprimida con gzip
#   evento       ruta   n   nivel   mensaje   el renglón n de esa bitácora no es un cobro:
#                                           es este aviso
#
# Cómo se arma una bitácora, sin azar. El renglón n lleva la hora inicio + (n-1)·paso
# segundos. Si no es un evento, es un cobro con
#   folio  F-(100000 + (n·7919 + semilla) mod 89999)        seis cifras, todos distintos
#   monto  (2000 + (n·7351 + semilla·13) mod 148000) / 100    en pesos, con centavos
# y queda «rechazado» si rechaza no es 0 y n > rechaza; si no, «aprobado».
# La huella es el sha256 del texto de la bitácora (en la -gz, del texto ya descomprimido):
# prepara la comprueba al terminar y verifica la usa para saber que nadie la cambió.
#
# Lo que agrega simula 03:
#   crece        ruta   texto        un renglón, en orden, tres segundos después del anterior
#
# Lo que pregunta la hoja de respuestas. verifica saca la respuesta buena del archivo:
#   pregunta   ruta   clave   forma       dato
#   formas:    renglon-de   el número del primer renglón que contiene «dato», tal cual
#              folio-en     el folio que trae el renglón número «dato»
#              hora-final   la hora (hh:mm:ss) del último renglón
#              renglones    cuántos renglones tiene el archivo
#              registros    cuántos renglones tiene, sin contar el encabezado
#              codigo-final la última palabra del último renglón «crece»
#              tipo         lo que contesta file; basta con que traiga «dato»
#
# Las fechas son fijas y están en UTC, como en la 01 y la 02: todas de 2025, así que la
# sala se ve igual hoy que dentro de un año. Nada de esto es de una persona ni de una
# empresa reales.
