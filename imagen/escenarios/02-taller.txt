# El taller de la lección 02, «Crear, copiar, mover y borrar sin miedo».
#
# Esta lista es la única definición del taller. La leen dos comandos:
#   prepara 02    arma en ~/practica/02/ lo que dicen los renglones carpeta y archivo
#   verifica 02   compara tu carpeta contra lo que piden los demás renglones
# Así no hay dos copias que se puedan contradecir.
#
# Las columnas van separadas por UN tabulador, no por espacios: así un nombre puede
# llevar espacios, como «aviso de corte.txt». prepara y verifica la leen igual, con
# IFS=$'\t' read -r. prepara revisa TODA la lista antes de borrar o crear nada: cada
# ruta tiene que quedar adentro de ~/practica/02/ solo por cómo está escrita (no
# vacía, no absoluta, sin «.» ni «..» ni tramos vacíos). Si una no, no prepara nada.
#
# Lo que prepara arma. Las rutas van dentro de ~/practica/02/:
#   carpeta   ruta   fecha
#   archivo   ruta   fecha   contenido   (el contenido es el resto del renglón: un solo renglón de texto)
# Las fechas son fijas y están en UTC, como en la lección 01: todas de 2025, así que se
# listan con su año y el taller se ve igual hoy que dentro de un año.
#
# Lo que pide cada ejercicio, y que verifica revisa:
#   crea-carpeta    ruta              2.1  la creas tú con mkdir
#   crea-archivo    ruta              2.1  lo creas tú con touch
#   copia           origen  destino   2.2  el destino YA existe, con otro contenido
#   copia-carpeta   origen  destino   2.2  se copia la carpeta entera, con cp -r
#   renombra        origen  destino   2.2  mismo lugar, otro nombre, con mv
#   mueve           origen  destino   2.2  el destino YA existe, con otro contenido
#   borra-patron    ruta              2.3  se borra, y tu patrón tiene que atraparlo
#   borra           ruta              2.3  se borra (una carpeta)
#   queda           ruta              2.3  NO se borra: tiene que seguir ahí, con su contenido
